# Blindly

App móvil para jugar al poker presencial de forma más dinámica.

## Estado actual (fase 1)

- Cronómetro de ciegas con niveles y breaks
- Presets: Turbo, Regular, Deep stack, y editor de niveles propios
- Aviso de cambio de nivel con sonido y vibración
- Pantalla siempre encendida mientras corre el reloj
- Salto manual al nivel anterior o siguiente
- Los datos se guardan en el teléfono

## Próximamente

- Salas de juego vinculadas a un host, con unión por QR
- Stack de fichas interactivo por jugador
- Ranking local y base de datos de partidas

## Cómo correrlo

    npm install
    npx expo start

Escaneá el QR con la app Expo Go.

## Tecnologías

Expo, React Native, TypeScript, Expo Router.
